# Dafan Arena — مشروع لعبة Android باستخدام Godot

مشروع أولي للعبة تصويب داخل ساحة مع دعم اتصال متعدد اللاعبين عبر ENet. يحتوي على كود المصدر وملف GitHub Actions لمحاولة بناء APK تلقائيًا.

## بناء APK عبر GitHub من الهاتف

1. فك ضغط الأرشيف.
2. أنشئ مستودع GitHub جديدًا باسم `Dafan-Arena`.
3. ارفع **محتويات** مجلد `Dafan_Arena` إلى جذر المستودع، مع الاحتفاظ بالمجلد المخفي `.github` وملف `project.godot` في الجذر.
4. افتح تبويب Actions وشغّل `Build Dafan Arena APK`، أو ادفع Commit إلى `main` أو `master` ليبدأ البناء تلقائيًا.
5. بعد نجاح المهمة، افتحها وانزل إلى Artifacts وحمّل `Dafan-Arena-Android-APK`، ثم فك ضغطه وثبّت `DafanArena.apk`.

## ما يفعله إعداد البناء

- يستخدم Godot 4.4.1 وJava 17 وAndroid SDK Platform 35 وBuild Tools 35.0.0.
- ينزّل Android export templates المطابقة لإصدار Godot.
- ينشئ debug keystore ويضبط مسارات Java وAndroid SDK في إعدادات Godot.
- يرفع APK كـ Artifact عند نجاح التصدير.

## ملاحظات مهمة

- أرشيف المشروع ليس APK جاهزًا؛ APK لا يتوفر إلا بعد نجاح GitHub Actions.
- ملف البناء يصلح أخطاء الإعداد الظاهرة سابقًا (قوالب التصدير، مسار JDK، ومفتاح debug)، لكن لا يمكن ضمان نجاح البناء حتى ينفذ على GitHub فعليًا.
- هذه نسخة لعبة أولية. اللعب عبر الإنترنت بين شبكات مختلفة قد يتطلب خادمًا عامًا وإعداد الشبكة؛ فتح الغرفة وحده لا ينشئ خدمة استضافة عالمية.
- APK الناتج موقّع بمفتاح debug للتجربة، وليس مفتاح إصدار تجاري ثابت.


**ملاحظة للبناء:** إعدادات Godot تحفظ في `~/.config/godot/editor_settings-4.4.tres` لهذا الإصدار؛ سير العمل يكتب هذا الملف بالمسار الصحيح ويتحقق من وجود Android SDK وقالب التصدير قبل التصدير.
